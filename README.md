# Calibre

A modern precision calculator with scientific functions, live results, and a paper-tape history.

## Features

- Standard and scientific modes
- Live evaluation as you type
- Keyboard input (digits, operators, Enter, Escape, Backspace)
- Deg / Rad, 2nd-function keys, memory (MC / MR / M+ / M−)
- History tape — tap a result to reuse it
- Local persistence of history, memory, and mode

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

```bash
npm run build
npm run preview
```

## Stack

React 19, Vite, TypeScript, Tailwind CSS v4.
